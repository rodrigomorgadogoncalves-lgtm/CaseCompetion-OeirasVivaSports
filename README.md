# CaseCompetion-OeirasVivaSports
The Oeiras Viva Sports project is a unified, omnichannel platform designed to combat sedentary lifestyles. It combines a digital app with gamification (OeirasCoins) and physical support hubs to ensure sports are accessible, engaging, and inclusive for all citizens. Suported by ISEG Junior Business Consulting and Câmara Municipal de Oeiras.
