# APRAD Consulting - Case Study

This repository contains the files developed for the **APRAD Consulting** project/case study. The project involves simulating client data for a wellness/nature activities app or program, as well as defining business metrics (OKRs and KPIs) and a final presentation of the results.

## 📂 Project Structure

The project is composed of the following main components:

### 1. Data Simulation (Monte Carlo)
- **`Simulação_MonteCarlo.ipynb`**: Python notebook responsible for generating a simulated dataset of 1000 users using conditional Monte Carlo simulations.
  - **Demographic Variables**: Age Group (Child, Youth, Adult, Senior), Gender, Marital Status, and Activity Level (Low, Medium, High).
  - **Activity Metrics**: The algorithm generates counts for various activities (No. of Runs, No. of Walks, Nature Trails, Group Classes, and Special Events) through a triangular distribution based on the user's activity level.
  - **Passport and Distance**: Calculates the estimated total distance (`Km Percorridos`) and the `Passaporte` (the total sum of activities performed).
- **`clientes_simulados.xlsx`**: The Excel output file automatically generated by the simulation notebook, containing the ready-to-analyze data.

### 2. Data Analysis and Visualization
- **`Visualizations.ipynb`**: Notebook dedicated to the visual exploration of the simulated data. It contains charts and analyses that provide insights into customer behavior (e.g., passport distribution by age group, correlation between activities and distances covered, etc.).

### 3. Strategy and Business
- **`OKR_KPI_evaluation_metrics.xlsx`**: Spreadsheet dedicated to strategic planning, where the Objectives and Key Results (OKRs) as well as the Key Performance Indicators (KPIs) for evaluating the project are defined and structured.
- **`APRAD 1.pdf`, `APRAD CONSULTING 2.pdf`, `APRAD CONSULTING 3.pdf`**: Supporting documentation, reports, and consulting project guidelines.

### 4. Presentation
- **`Presentation.pptx`**: The final PowerPoint presentation containing the case study conclusions, strategic proposals, and a summary of the insights obtained through data analysis.

## 🚀 How to Run

To run the local notebooks, you need to have Python installed along with the following libraries:
- `numpy`
- `pandas`
- `matplotlib` / `seaborn` (used for visualizations)

You can install the dependencies by running:
```bash
pip install numpy pandas matplotlib seaborn openpyxl
```

**Execution order:**
1. Run `Simulação_MonteCarlo.ipynb` to generate the database file `clientes_simulados.xlsx`.
2. Run `Visualizations.ipynb` to view the charts and resulting exploratory analysis.
